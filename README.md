# USB & Wi-Fi Proxy Bridge (Android Termux to Ubuntu)

Скрипты для быстрой автоматизации раздачи VPN-трафика со смартфона (через Android-клиенты вроде JumpJump VPN / Happ) на любой рабочий ПК под управлением Ubuntu. Позволяет прозрачно менять внешний IP-адрес в консоли и обходить лимиты (например, сессии *free usage* в OpenCode/Fetch/Node.js).

## Как это работает
Бесплатные VPN-клиенты на Android изолируют сетевой стек и не создают прокси-портов для локальной сети. Данное решение обходит это ограничение:
1. Легковесный Python-скрипт на телефоне (в Termux) поднимает локальный HTTP/HTTPS-прокси.
2. Трафик с ПК заворачивается в телефон либо по медному кабелю через безопасный отладочный мост `adb forward`, либо напрямую по воздуху через Wi-Fi точку доступа.
3. Android-клиент VPN на телефоне прозрачно подменяет IP-адрес для всех уходящих запросов.

## ⚡ Быстрый старт на новом ПК (Ubuntu)

Когда вы садитесь за новый компьютер, достаточно выполнить три шага.

### Шаг 1. Настройка компьютера (Один раз)
Склонируйте репозиторий (или скопируйте скрипт) и запустите инициализацию:
```bash
bash init_proxy_pc.sh
```
*Скрипт автоматически установит `adb`, `netcat`, создаст утилиту подключения в домашней директории и пропишет умный автоподхват переменных `$HTTP_PROXY` / `$HTTPS_PROXY` в ваш `~/.bashrc`.*

**После завершения настройки обязательно перезапустите терминал!**

### Шаг 2. Подготовка телефона
1. Убедитесь, что на смартфоне включена **«Отладка по USB»** в настройках разработчика.
2. В приложении **Termux** должен быть запущен прокси-сервер (`proxy_server.py`) на порту `2080`.
3. Включите ваш VPN-клиент на телефоне (**JumpJump VPN** или аналогичный).

### Шаг 3. Запуск соединения

Выберите один из двух удобных вариантов работы:

#### Вариант А: Работа без проводов (через Wi-Fi точку доступа)
1. Включите на телефоне **Точку доступа Wi-Fi**.
2. Подключите ПК к этой Wi-Fi сети.
3. Откройте **любой новый терминал** на Ubuntu. Система сама обнаружит телефон по воздуху и применит прокси.

#### Вариант Б: Работа по кабелю (через USB)
1. Подключите телефон к ПК по USB-кабелю.
2. Выполните в терминале команду инициализации моста:
   ```bash
   ~/connect_phone.sh
   ```
3. Откройте новый терминал — прокси применится автоматически ко всем утилитам в сессии (включая OpenCode, `curl` и системные запросы GNOME).

## 🛠 Полезные команды на ПК

* Проверить текущий внешний IP-адрес и работу прокси:
  ```bash
  curl ifconfig.me
  ```
* Проверить, применилась ли переменная окружения:
  ```bash
  echo $http_proxy
  ```
* Временное ручное отключение прокси в текущей вкладке:
  ```bash
  proxy-off
  ```
* Принудительное обновление конфигурации (перечитать порты):
  ```bash
  proxy-on
  ```

## 📱 Код прокси-сервера для Termux (`proxy_server.py`)
Скрипт на стороне телефона должен слушать адрес `0.0.0.0` для универсальной работы:
```python
# Запуск на телефоне: python proxy_server.py
# Скрипт принимает трафик от ПК и отдает его в сетевой стек Android с активным VPN
```
